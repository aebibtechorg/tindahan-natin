# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0+12] - 2026-05-28

### Added
- Two-finger rotation support for shelves in the Store Map.
- Support for negative angles when rotating shelves.
- Print transaction history.

## [1.0.0+11] - 2026-05-27

### Added
- Real-time updates for Lista and Products.
- Mark lista entries as paid/unpaid with UI updates.
- Interstitial ads on Home screen.
- Store stats and quick actions on Home screen.
- Better usability for Add Lista Entry screen.

### Changed
- Updated Privacy Policy and Terms for sales/credit data.
- Improved Home Screen layout and readability.
